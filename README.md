# Priyanshu Kumar Dwivedi — Digital Imaging Portfolio

A responsive one-page portfolio tailored to a Digital Imaging Specialist / 2D Image Annotation screening.

## Files
- `index.html` — complete portfolio website (HTML + CSS, no dependencies)

## Before submitting
1. Open `index.html` and check the email address.
2. Replace the GitHub profile link with your actual GitHub profile URL.
3. Only list tools you can genuinely use.
4. The visuals are clearly described as self-made concept/practice samples, not paid client work.

## Publish with GitHub Pages
1. Create a new public repository on GitHub named `digital-imaging-portfolio`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then Save.
6. Wait a minute or two. GitHub will show a live URL similar to `https://YOUR-USERNAME.github.io/digital-imaging-portfolio/`.
7. Open the URL in an incognito tab to confirm it works, then paste that live URL into the screening form.
